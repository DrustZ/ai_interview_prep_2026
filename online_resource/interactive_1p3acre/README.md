# 交互式面试题库 App（OpenAI / Anthropic）

一亩三分地题库页布局的本地网页版：左侧多维 filter + 题目列表，点进去看题目/答案/帖子/链接。**完全离线，双击即用。**

## 打开方式

```
open index.html      # 直接双击也行
```

浏览器打开即可，无需服务器、无需联网（marked / highlight.js 已本地打包在 vendor/）。

## 功能

- **公司 tab**：全部 / OpenAI / Anthropic（顶部快捷切换）
- **侧栏 filter**（7 组：公司/题型/状态/类别/频率/岗位/轮次）——**全部可多选、可自由组合**：
  - 同一组内多选 = **OR**（如「类别」里选 coding + system-design = 两者都要）
  - 跨组 = **AND**（如 类别=coding + 题型=OJ = 既是 coding 又是 OJ）
  - 每个 chip 的数字会随其他已选 filter 实时联动
  - 顶部「已选」条显示当前所有条件，点 ✕ 移除单个，或「全部清除」
- **搜索框**：标题 + 标签 + 正文关键词（叠加在 filter 之上）
- 类别说明：外链帖/OJ 题原本无类别，已按标题自动归类为 coding / ml-coding / system-design，便于组合筛选
- **列表**：按「有正文 → 频率 → 最近考」排序，每行带公司/类别/频率/难度/正文标记徽章
- **详情面板**：
  - 含正文的题（48 题）：渲染完整题目 + 参考解（代码高亮）
  - 仅链接的题：显示元数据 + 两个按钮
    - **↗ 原帖 / 站内看题**：打开 1p3a 原始链接
    - **🔓 用解锁工具打开**：自动复制题目链接 + 打开你的解锁工具，粘进搜索框即可

## 数据规模

203 题：OpenAI 111 + Anthropic 92。其中 48 题含完整正文/答案（12 篇情报 briefings + 46 篇解锁的外链帖编辑版）；其余会员题/OJ 题给元数据 + 链接。

## 重新构建

题库更新后（比如又解锁了新帖，HTML 放进 `../raw/1p3a_html/`）：

```
python3 build_app.py     # 重新生成 data.js
```

数据源：`../raw/{openai,anthropic}_clean.json`（题库元数据）+ `../raw/1p3a_html/*.html`（解锁的编辑版）。

## 会员题 / OJ 题（无原帖）怎么办

这些题是 1p3a 自己的会员题库，**没有独立原帖，解锁工具（只认数字 thread id）无法处理**，正文 body 在会员区锁定。所以详情页改为提供：

- **题目概要**：会员摘要 overview（80 道 qbank 全都抓到了，1-2 句说清题目在考什么）
- **🔗 相关资源**：自动匹配到的可解析链接——本地已解锁的外链帖正文、hack2hire 完整题解、deep-ml 手写题、原始爬取来源（1p3a bbs / 各网站）。**可直接丢给第三方解析**
- **📓 本地笔记覆盖**：`my_interview_prep` 里哪份笔记讲过这题
- **🧩 站内关联题**：1p3a 的 related 关联题

63/140 道会员+OJ 题有交叉引用，80 道有概要。数据由 `build_xref.py` 生成（匹配算法：标题+slug token 相似度 + 标签加权）。

## 重新构建交叉引用

```
python3 build_xref.py    # 重新匹配资源 → /tmp/qbank_xref.json
python3 build_app.py     # 合并进 data.js
```

## ⚠️ 解锁工具配额 & 续解锁

解锁工具是 **250 次/卡** 的配额（`访问限制为250次卡`）。当前这张卡已用满。已解锁并嵌入的内容都在 App 里（48 题完整正文 + 31 篇真实面经帖 + 80 题概要）。

**配额重置后（通常按天）或换新卡**，续解锁剩余"被题目引用但没拿到"的帖子：
```
# 在 new/ 目录下（如换卡，先改 resume_unlock.py 里的 CODE）
python3 raw/resume_unlock.py
cd interactive_1p3acre && python3 build_app.py   # 重新嵌入
```

## 能拿到 vs 拿不到

- ✅ **外链帖 / 普通面经帖**：有数字 thread id，工具可实时解锁（已做）
- ❌ **OJ 题（60 道）**：1p3a 自己的 LeetCode 式练习题，题面是会员 OJ 内容、无帖子、UUID 非 thread id——工具够不着。只能登录你自己的 1p3a 会员账号看
- ⚠️ **qbank 官方编辑正文**：会员锁定、无独立帖子——但其背后的真实面经帖已解锁嵌入

## 说明

- 解锁工具是第三方 HTTP 服务，浏览器因混合内容/跨域限制无法在页面内直接解锁，所以采用"复制链接+跳转工具"的方式。
- 交叉引用是启发式匹配，个别可能不精确；每条都标了来源类型和匹配度，自行判断。
