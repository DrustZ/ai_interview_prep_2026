2023年下半年我网申了deepmind伦敦的几个岗位。应该过了不到一个月，deepmind给了一个面试机会。我分析给面试主要是因为背景比较match。research scientist岗位，trust & ai ethics方向。拿到deepmind的面试机会还是挺兴奋的，毕竟是top。

面试总共应该有5轮。可惜止步第三轮。

第一轮hiring manager，总共半小时。hiring manager自我介绍说在🐶家和dp总共待了8年，面试内容主要聊了一下这个岗是做什么的，然后就是我自我介绍、过简历。最后还老哥还出了一道case design的题，口头简单回答了一下，大概不到五分钟，具体问题忘记了。

第二轮hr的bq，半小时。答题方式感觉就是表现出对ai的热情和对ai ethics的重视。不知道其他方向是不是可以这么答。

第三轮技术面，分三次，每次一个小时。考察的内容是ml、cs知识（包括一个coding）、math（和ml相关的，linear algebra）。需要认真仔细准备，可以跟hr约把这三次时间分开。我是每个面试相隔了一个星期。

第四轮应该是给talk，给不同的人讲，可能要讲好几次，第五轮应该是team match。

dp算抛骰子概率的问题

    def dicesProbability(self, n: int) -> List[float]:
        dp = [0] * (6 * n + 1)
        # 用1颗骰子时和为1~6的方案数
        dp[1:7] = [1] * 6

        # 从使用2颗骰子一直遍历到使用n颗
        for num in range(2, n + 1):
            # 最大和为6x骰子数，最小和为1x骰子数
            for s in range(6 * num, num - 1, -1):
                # 注意每次需要先初始化为0，否则它将是使用n-1颗骰子时的状态
                dp = 0
                # 最后一颗骰子的点数范围
                for i in range(1, min(6, s - num + 1) + 1):
                    dp += dp[s - i]

        # 总方案数
        total = pow(6, n)
        # 返回概率
        return [dp / total for s in range(n, 6 * n + 1)]
